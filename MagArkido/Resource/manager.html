Pattern Editor Guide

Block List

Each row is one box in the pattern. Drag the ⠿ handle to reorder — list order = draw order in the preview (first = furthest back). Use ↑ / ↓ buttons or drag. Click a block to select it; click again to deselect. You can also click directly on the canvas to pick a block.

Position & Size
FieldMeaning
xLeft/right offset (red axis)
yFront/back depth offset (green axis)
zHeight offset from ground (blue axis)
wWidth of the block (X extent)
dDepth of the block (Y extent)
hHeight of the block (Z extent)

Only proportions matter — blocks are scaled to fit the target group's bounding box.

Expression Tokens
TokenMeaning
r1 … r6Random 0 or 1, fixed per building instance
rand(n)Random integer 0 to n−1, per instance
lv(t, 3.5)Floor count = target height ÷ 3.5 m per floor
w, d, h, x, y, z…Resolved value of another field in this block

Examples:

"lv(t,3.5)*3"floor count × 3 — scales with building height
"r1*10+20"randomly 20 or 30 per building
"70+r4*4"randomly 70 or 74, independent of r1–r3
"rand(4)*5"one of four evenly-spaced values
"lv(t,3)+r2*2"floor count with random 2-unit variation
"w*0.5"half of this block's own width

Use fx on any field to switch it to expression mode.
